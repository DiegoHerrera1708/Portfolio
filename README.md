## 🚀 Cómo Ejecutar Localmente

Si deseas explorar el código o probar el proyecto localmente:

### Prerrequisitos

* Tener **Git** instalado en tu equipo.

### Instalación

1. **Clonar el repositorio**

```bash
git clone https://github.com/DiegoHerrera1708/Portfolio.git
```

2. **Entrar en el directorio del proyecto**

```bash
cd Portfolio
```

3. **Abrir en el navegador**

* Haz doble clic en `index.html` o utiliza la extensión **Live Server** de VS Code para un servidor local.
